# ClaudeInstall: Distribution-Independent Installer Framework
---------

> ClaudeInstall is a distribution-independent system installer, with an advanced partitioning
> feature for both manual and automated partitioning operations. ClaudeInstall is designed to
> be customizable by distribution maintainers without the need for cumbersome patching,
> thanks to third-party branding and external modules support.
